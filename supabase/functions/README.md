# Edge Functions

Vide en J1, volontairement : la première fonction réelle est `cloturer-carte`, au jalon J3.

Y vivront les opérations que le serveur doit arbitrer — clôture de carte et calcul
de commission, envoi des reçus, encaissement des abonnements — ainsi que la clé de
service, qui ne quitte jamais cet emplacement.
